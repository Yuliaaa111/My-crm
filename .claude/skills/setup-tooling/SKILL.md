# Setup Tooling

Настройка ESLint, Prettier, `tsconfig.json` и `vite.config.ts` по
эталону из `references/` этого скилла. Ничего не ломает и не
переписывает то, что уже настроено и работает.

## 1. Проверить текущее состояние

Проверить, что уже есть в проекте:

- `.prettierrc`, `.prettierignore`
- `eslint.config.ts`
- `tsconfig.json`
- `vite.config.ts`
- зависимости в `package.json` — ESLint, Prettier и все плагины,
  перечисленные в `references/dependencies.md`.

## 2. Если уже настроено — не трогать

Если файл существует и рабочий — не переписывать его "на всякий
случай" и не накатывать эталон поверх. Сообщить пользователю, что
именно уже настроено и поэтому пропущено.

## 3. Если чего-то не хватает — сначала спросить разрешение

Если файла нет или в `package.json` не хватает зависимостей —
**прежде чем что-либо ставить или изменять, безусловно спросить
разрешение у пользователя**, даже если настройка тулинга была прямым
изначальным запросом пользователя в этом же диалоге. Показать:

- список файлов, которые будут созданы/изменены;
- список npm-пакетов, которые будут установлены (см.
  `references/dependencies.md`).

Только после явного "да" — выполнять.

## 4. Применение эталонов

При подтверждении:

- установить недостающие зависимости;
- создать недостающие конфиги на основе `references/.prettierrc`,
  `references/.prettierignore`, `references/eslint.config.ts`,
  `references/tsconfig.json`, `references/vite.config.ts`.

Если в существующем конфиге уже есть проектно-специфичные вещи
(например кастомные `paths` в `tsconfig.json`, свои `ignores` в
`eslint.config.ts`) — не затирать их эталоном бездумно. Согласовать с
пользователем, как объединить существующее с эталоном.

Точечные project-specific исключения линтера из легаси-кода (например
отключение правила для одного конкретного файла) — не переносить в
новый проект по умолчанию; это специфика конкретного кода, а не часть
стандарта. Если в целевом проекте есть похожий случай — уточнить у
пользователя отдельно.

## 5. Git

Ничего из настроенного не коммитить и не пушить самостоятельно —
действуют общие правила `.claude/rules/safety-rules.md`.
